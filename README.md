# 787–9 Dreamliner · Flight Atelier

> 波音 787-9 梦想客机 3D 沉浸式飞行工坊 · Three.js 单文件离线场景

## 项目简介

《787–9 Dreamliner · FLIGHT ATELIER》是一个自包含的纯前端 3D 航空交互工坊。基于 Three.js 实现了波音 787-9 客机的完整机体精细渲染、动态机翼气动弯曲、发动机涡轮叶片转动、机舱客室视角切换以及全景云海航行情境。

## 核心体验

- **高精度机体模型与涂装**：包含机身、驾驶舱视窗、客舱舷窗、超临界机翼及客机标志性掠角翼梢。
- **动态气动与引擎系统**：真实重现 GEnx / Trent 1000 涡扇发动机叶片旋转、巡航姿态扰流板与副翼微调。
- **环境与大气光照**：万米高空云海掠影、晨曦与落日航向光影变化。
- **零依赖单文件**：单文件自包含 HTML，双击即开，极速畅享 60FPS 丝滑飞行质感。

## 运行方式

无需任何本地服务器或构建命令，直接使用现代浏览器打开 `index.html` 即可。
